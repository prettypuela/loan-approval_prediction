# Loan Approval Prediction Using Supervised Machine Learning

## Project Overview
This project uses supervised machine learning to predict whether a loan application will be approved or rejected.

## Dataset
The dataset contains information about loan applicants, including income, education, credit history, and property area.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## Model
I used Logistic Regression to train a model to predict loan approval.

## Results
The model achieved **86.18% accuracy** on the test dataset.

The confusion matrix and classification report were used to examine correct and incorrect predictions.

## Conclusion
This project helped me understand data cleaning, data preparation, supervised machine learning, and model evaluation. The model still makes mistakes, so further improvement and testing would be needed before real-world use.
